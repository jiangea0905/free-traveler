# UI/UX Plan — Free Traveler

**Document ID:** UIUX-TRAVEL-001
**Revision:** 1.0
**작성일:** 2026-09-11
**기반 문서:** `docs/01_PRD.md`, `docs/02_SRS_BASELINE.md`, `docs/PROJECT_SCOPE.md`, `docs/03_UI_COVERAGE_ANALYSIS.md`
**참고 자료:** `design-reference/vendor/airbnb/DESIGN-airbnb.md`

이 문서는 `03_UI_COVERAGE_ANALYSIS.md`에서 확정한 5개 Screen(SCR-001~005)에 실제 디자인 규칙과 Section 구성을 배치한다. Airbnb 참고본은 **구조적 영감**(흰 캔버스 위 단일 포인트 컬러, 얕은 그림자 1단계, 둥근 모서리, 여백이 넓은 편집형 섹션과 밀도 높은 카드 그리드의 대비)만 가져오고, Rausch 컬러값·Cereal 서체·로고·워드마크·"Guest favorite" 같은 상표적 요소는 사용하지 않는다. 색상·타이포·둥근 정도는 Free Traveler 고유 값으로 새로 정의한다.

`PROJECT_SCOPE.md`에서 EXCLUDED로 정한 기능(전체 CMS, 미디어 업로드 워크플로, 감사 로그, 자동 백업·장애 알림·부하 테스트, 외부 이메일 연동, 분석 대시보드 등)은 이 UI 계획에서도 화면으로 만들지 않는다.

## 3. Section 배치·콘텐츠 밀도 규칙 요약

- 모든 화면은 Header와 Footer 사이에 목적이 분명한 Section을 순서대로 배치하고, 같은 Card 패턴만 반복하지 않도록 Hero·Card Grid·좌우 분할·Chip 목록·3단계 안내·CTA Banner를 교차 사용한다.
- 각 Section은 제목 + 1~3문장 설명 + 실제 콘텐츠 또는 명확한 CTA로 구성한다.
- Lorem ipsum, "준비 중", "정보 확인 필요" 같은 placeholder 문구와 의미 없는 빈 Card를 두지 않는다. 데이터가 없는 경우에도 안내 문장 + 이용 방법 + 다음 행동 CTA를 갖춘 Empty State로 대체한다.
- Hero는 1440px 화면에서 뷰포트 전체 높이를 차지하지 않으며(권장 480~560px), 스크롤 없이도 다음 Section의 제목 일부가 보이도록 여백을 조절한다.
- 사진에는 실제 장소·인물 행동을 설명하는 alt 텍스트를 붙인다(예: `alt="교토 후시미 이나리 신사의 붉은 도리이 행렬"`), 장식용 아이콘은 `alt=""`로 처리한다.

## 8. SCR-005 `/account` 계정·관리 (역할 기반, 고정 Section 수 없음)

**목표:** 로그인·가입하고 프로필과 내 활동(글·요청·즐겨찾기·차단)을 관리하며, 관리자 권한이 있으면 신고 상태와 외부 URL만 처리한다. 역할에 없는 탭은 렌더링하지 않는다.

### 8.1 Guest (비로그인)

탭 없이 단일 뷰로 구성한다.

| Section | 구성 |
|---|---|
| 계정 기능 Intro | "로그인하면 동행 모집·참가 요청·즐겨찾기를 이용할 수 있어요" 설명 |
| 로그인/가입/재설정 Card | 카드 내부 토글(로그인 · 가입 · 비밀번호 재설정), 이메일 기반 |
| 로그인 후 가능한 기능 | 아이콘+텍스트 3~4개: 동행글 작성, 참가 요청, 즐겨찾기, 내 활동 관리 |
| 보안 안내 | 성인 확인 절차와 개인정보 최소 수집 원칙 안내 배너 |

### 8.2 Member (로그인, 일반 회원)

탭: **프로필 / 내 활동**

| 탭 | Section 구성 |

| 내 활동 | "새 동행글 작성" CTA(→ `/travel-tools` 동행 탭) 상단 배치, 이어서 4개 목록 블록: 내 글(상태 배지 + 수정/마감), 받은 참가 요청(승인/거절 버튼), 즐겨찾기(→ SCR-001 상세 Drawer 딥링크), 차단 목록(차단 해제 버튼) |

### 8.3 Admin (관리자 권한 보유)

탭: **프로필 / 내 활동 / 관리자**

| 탭 | Section 구성 |
|---|---|
| 관리자 | 관리 Intro("이 관리자 화면은 신고 상태 변경과 외부 URL 설정만 처리합니다"), 신고 목록(대상·사유·상태 변경 버튼: 검토중/처리완료/기각), 항공·숙소 외부 URL 설정 Form(HTTPS만 저장 허용, 저장 실패 시 사유 표시) |

관리자 탭에는 통계 차트나 대시보드를 두지 않는다. 신고 큐는 목록+상태 변경 버튼으로만 구성한다.

## 10. Dashboard 관련 명시

관리자 화면(SCR-005 관리자 탭)과 그 외 어떤 화면에도 통계 차트, KPI 위젯, 복잡한 대시보드를 만들지 않는다. 관리자 기능은 `PROJECT_SCOPE.md`가 정한 범위(신고 상태 변경, 외부 URL 설정)로 제한한 목록형 UI로만 구성한다.
